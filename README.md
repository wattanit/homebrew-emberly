# homebrew-emberly

Official Homebrew tap for [Emberly Code](https://github.com/wattanit/emberly-code), an AI coding agent for the terminal.

## Install

```sh
brew tap wattanit/emberly
brew install emberly
```

Or in one line:

```sh
brew install wattanit/emberly/emberly
```

## What's here

The `Formula/emberly.rb` file in this repo is generated and kept in sync automatically by [cargo-dist](https://github.com/axodotdev/cargo-dist) on every tagged release of the main project — it isn't hand-maintained. Don't edit it directly; changes belong in [emberly-code](https://github.com/wattanit/emberly-code)'s release configuration instead.
